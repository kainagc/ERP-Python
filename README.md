# ERP 

Desenvolvimento de um ERP para a empresa, marcenaria de moveis sob medida em MDF.
Foco em usabilidade e acessibilidade, pois os usuários que utilizaram, todos fazem utilização de óculos de grau, e todos já passaram de 40 anos de idade 

# Ferramentas

React no desenvolvimento do front, o beckend vai ser desenvolvido em Python, banco de dados vai ser utilizado o PostgreSQL
